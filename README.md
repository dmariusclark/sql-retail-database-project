# Retail Inventory & Order Management Database

This project demonstrates the design and implementation of a relational database using MySQL.

## Features
- Designed normalized database schema with multiple related tables
- Implemented primary and foreign key constraints
- Managed customers, orders, products, inventory, and suppliers

## Key SQL Concepts Used
- INNER JOIN and LEFT JOIN
- Aggregation (SUM, COUNT)
- GROUP BY and HAVING
- Data updates using JOIN
- Schema evolution with ALTER TABLE

## Example Insights
- Calculated total order value using item-level pricing
- Identified repeat customers based on order frequency
- Combined product, inventory, and supplier data for operational visibility

## Files
- schema.sql → database structure
- data.sql → sample data
- queries.sql → business queries
